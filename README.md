# ShellHacks Hardware

LaneTalk's ShellHacks prototype, with ESP32-CAM firmware and a laptop companion app.

## Contents

- `firmware/CameraWebServer/` — ESP32-CAM access point and MJPEG stream firmware.
- `laptop/lanetalk/` — laptop-side camera, detection, coaching, and speech modules.

For board setup, wiring, and firmware upload instructions, see [`firmware/CameraWebServer/README.md`](firmware/CameraWebServer/README.md).
